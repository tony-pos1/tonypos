# 🍽️ Thai Restaurant POS (ระบบจัดการร้านอาหารและคิดเงิน 2 หน้าจอ)

ระบบขายหน้าร้าน (Point of Sale) สำหรับร้านอาหารและคาเฟ่ รองรับการทำงานแบบ Offline-first, ระบบ 2 หน้าจอ (จอพนักงาน + จอลูกค้า), และแสดง QR พร้อมเพย์ของทางร้านโดยตรง

---

## 🚀 วิธีตั้งค่า GitHub Pages ให้เปิดบนแท็บเล็ต/มือถือได้ (แก้ปัญหาจอขาว)

สาเหตุที่เปิดบนแท็บเล็ตแล้วขึ้น **จอขาว (Blank White Screen)**:
เนื่องจากโปรเจกต์นี้เขียนด้วย **React + Vite + TypeScript** ซึ่งเว็บเบราว์เซอร์บนแท็บเล็ตไม่สามารถอ่านไฟล์ `.tsx` ดิบๆ ได้โดยตรง ต้องผ่านการ Build (Compile) เป็น JavaScript ก่อน แต่ในการตั้งค่า GitHub Pages ค่าเริ่มต้น มันพยายามเปิดไฟล์ดิบจากโฟลเดอร์หลัก

### ✅ วิธีแก้ไขเพียง 2 ขั้นตอน (ทำครั้งเดียว):

1. **เปิดหน้า GitHub คลังเก็บโค้ดของคุณ (`tonypos`)**
2. ไปที่แท็บ **Settings** ด้านบน (รูปฟันเฟือง)
3. ที่เมนูด้านซ้าย เลือกหัวข้อ **Pages**
4. ตรงหัวข้อ **Build and deployment > Source**:
   - ให้เปลี่ยนจาก **"Deploy from a branch"** ➡️ เป็น **"GitHub Actions"**
5. เมื่อเปลี่ยนเป็น **GitHub Actions** แล้ว:
   - ระบบจะใช้ไฟล์ `.github/workflows/deploy.yml` ทำการ Build อัตโนมัติทุกครั้งที่คุณ Push โค้ด
   - รอประมาณ 1-2 นาที ให้แท็บ **Actions** ขึ้นเครื่องหมายถูกสีเขียว (Workflow Succeeded)
6. เปิดลิงก์ GitHub Pages บนแท็บเล็ตอีกครั้ง (เช่น `https://tony-pos1.github.io/tonypos/`) ตัวแอปจะแสดงผลขึ้นมาใช้งานได้ทันที 100%!

## 🖥️ คุณสมบัติเด่นของระบบ
- **Offline-First 100%:** ข้อมูลเมนู ออเดอร์ โต๊ะอาหาร เก็บในเครื่องผ่าน IndexedDB ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องเสียค่าบริการรายเดือน
- **ระบบ 2 หน้าจอ (Dual-Screen Retail POS):**
  - **จอหน้า (จอสัมผัสพนักงาน):** กดสั่งอาหาร คิดเงิน จัดการโต๊ะ
  - **จอหลัง (จอลูกค้า):** ซิงค์รายการอาหารแบบเรียลไทม์ และเด้งรูป QR พร้อมเพย์ของร้านขนาดใหญ่ให้ลูกค้าสแกนทันทีเมื่อกดชำระเงิน
- **Custom QR Only:** ใช้รูปภาพป้าย QR Code พร้อมเพย์จริงของร้านเท่านั้น ปลอดภัย ไม่มีการสร้าง QR จำลองขึ้นมาใหม่
- **Bilingual:** รองรับ 2 ภาษา (ภาษาไทย / English)
